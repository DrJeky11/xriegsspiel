# Reference photographs

These are real, dated reference photographs, not game artwork or evidence of current equipment fit. Each `*-thumbnail.*.webp` and `*-detail.*.webp` is a resized, padded derivative retaining the entire source frame. No ship details were generated or reconstructed.

The canonical attribution, license links, photographed subjects, dates, checksums and sources are in `catalog/references.json` in the repository and in each card's **Photo credits & role sources** control. Image licenses apply to these derivatives independently of application code. In particular, derivatives of the Type 072A and Type 056 photographs retain CC BY-SA 4.0.
