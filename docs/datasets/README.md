## Using this collection

- Cite the exact edition and both the printed page and one-based PDF page when practical. Covers and change sheets make these differ.
- Preserve the original files. Any future extraction should retain its source hash, page/section, extraction method, and review status.
- Keep a publication's description separate from an XRiegsspiel interpretation and from an implemented game parameter. These publications do not provide an approved executable ruleset.
- The Army documents state public-release/unlimited-distribution status. The journal article states CC BY 4.0. Record individual figure/tool attributions when adapting material; public distribution alone does not settle every embedded item's reuse terms.

No PDF was modified during this review. Temporary text extractions and page renders were kept outside the repository.
